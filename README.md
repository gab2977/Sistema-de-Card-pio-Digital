# Cardápio Digital - Sabor & Arte

Projeto de site institucional e cardápio digital responsivo criado com **HTML5** e **CSS3** para uma hamburgueria e cafeteria fictícia.

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório público no GitHub com o nome exatamente igual a: `cardapio-digital`
2. Envie os arquivos `index.html`, `style.css` e o `README.md` para o repositório criado.
3. No seu repositório do GitHub, vá em **Settings** > **Pages**.
4. Em **Build and deployment**, selecione a branch `main` (ou `master`) e clique em **Save**.
5. Aguarde alguns minutos e acesse o link gerado pelo GitHub Pages.
